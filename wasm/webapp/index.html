About This Tool

Perform satellite orbit propagation using two-body (Keplerian) dynamics. This version runs entirely in your browser using WebAssembly - no server required!

  • Frame: J2000 Earth-centered inertial (EME2000)
  • Units: Position in meters, Velocity in m/s
  • Time: UTC timezone (ISO-8601 format)
  • Engine: Two-Body Dynamics (Keplerian propagation)
